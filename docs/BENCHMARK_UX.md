# Benchmark 工作流与界面

本轮统一现有 Benchmark 页面，不改变公开 v2、私有 v3 或 Comparison v1 契约。
沿用 EasyMSA 的 Inter 字体、绿色主操作、表单控件、页宽和浅色背景。

## 使用路径

- 方法对比：从关于页进入，选择数据集、指标和方法，查看公开成绩或提交自己的程序。
- 提交评测：填写公开 GitHub 仓库；邮箱可选，方法名称、版本和序列类型在更多设置中。
- 即时示例：同一入口切换至 MSA-Kit，直接打开已完成的真实结果；切回时保留表单草稿和键盘位置。
- 运行任务：显示真实阶段、已处理数据集数和取消入口，提示可以从最近评测回来查看。
- 完成任务：进度收起，优先展示比较图；保存链接与恢复文件放在保存菜单中。浏览器保存失败时，仍直接显示恢复操作。
- 最近评测：查看此浏览器的任务，或用结果链接、恢复文件找回任务。空列表提供提交和示例两个入口。

示例仍是固定 commit `c49b49f748902798ce90c21cb734baf11ea4a3f9` 的25组完成、1组超时。
示例不创建任务、不消耗额度、不发送邮件、不调用 Docker。

## 阅读与交互

所有 Benchmark 页面使用一致的局部导航；网站主导航保持原样，入口仍在关于页。
本程序仍以绿色菱形突出，Q 优先、归一化 SP 后备。时间—质量与内存—质量图同时展示，
质量、刻度和局部放大使用一组共用控件；Q／TC 默认开启局部放大，关闭后以 `zoom=0` 保存到链接，刷新仍保持关闭；完整表格同时列出时间、内存、归一化 SP、Q 和 TC。
图表标签优先靠近自己的点，坐标不变。表格中的数字按列右对齐，完整精度可在提示和下载中查看。

宽屏两图并排，手机上下排列，无需切换视图才能找到不同指标。表格不限制纵向高度，
纵向只滚动页面，列超宽时在表格内横向滚动。数据集目录保持当前选择与位置。
“下载数据”提供当前数据集的 FASTA 和全部 26 组输入的 ZIP；CSV／JSON 由“导出成绩”提供。
文件准备与发布方式见 [Benchmark 数据集下载](BENCHMARK_DATASET_DOWNLOADS.md)。

方法一览按每个数据集的原始数值统计各指标第一的次数；并列均计入，有效值只有一项时计入该方法，
缺失值不参与。全同分和单个有效值的矩阵颜色仍保持中性，颜色强调不参与次数计算。
指标说明使用页面外层浮层，支持聚焦、悬停和 Escape 关闭，不增加表格纵向滚动范围。
矩阵实际放得下时，宽屏表头随页面固定；文字放大或表格超宽时，保留局部横向滚动。
手机结果表使用卡片完整宽度，首次显示方法、状态和完整的时间数值。

`/benchmark` 默认进入总览（方法一览＋全部数据集矩阵），`/benchmark?view=matrix` 等价；
带 `dataset` 参数的旧链接仍直接打开该数据集报告。公共数据在同一次浏览中共享已校验快照，连续选择数据集不重新显示加载页。
仅切换数据集时保留阅读位置；浏览器返回仍恢复历史位置。Benchmark 不使用整页淡出淡入：
切换「方法对比／提交评测／最近评测」时导航栏保持不动，只有下方内容轻微上浮淡入；在数据集之间切换时页面完全静止。

仓库、序列类型错误在相关字段处显示并定位焦点；网络错误保留表单和幂等重试。
弹出菜单支持外部点击和 Escape 关闭；窄屏导航和下载菜单始终保持在屏幕内。
隐藏的恢复文件控件不再显示为普通输入框。

## 开发位置

- `BenchmarkNavigation.tsx`：统一导航与流程指示。
- `BenchmarkProgress.tsx`：真实任务进度和保存菜单。
- `workflow.css`：与网站一致的样式、字号和响应式规则，仅作用于 Benchmark。
- `BenchmarkSubmitPage.tsx`：正常提交与即时示例，包含内存中的表单草稿。
- `ComparisonCharts.tsx`、`ComparisonView.tsx`：图表、指标选择、目录和菜单。
- `useDismissDetails.ts`：原生 details 菜单的外部点击／Escape 关闭行为。
- `e2e/benchmark-workflow.spec.ts`：草稿、示例、真实任务状态替身、恢复、手机和键盘回归。

## 本地预览

本轮的预览服务是只读环境，使用真实公开快照，可以完整体验 MSA-Kit。
提交页会明确标注本地预览并提供正式网站链接；它不连接真实任务执行接口。
正常提交、排队、完成、取消及失败路径由浏览器测试中的接口替身验证。
