# 用户程序对比与 MSA-Kit 即时示例

完成评测后，用户任务页默认打开“与其他方法对比”，将本程序与 Clustal Omega、
MAFFT、MUSCLE 5、HAlign、FMAlign2、minipoa 放在同一数据集下比较。
“我的成绩”保留原单程序表格和原始 CSV／JSON 下载。入口仍位于 Benchmark 内。

## 普通任务与图表

任务地址为 `/#/benchmark/runs/:runId`，继续使用浏览器保存的任务密钥或原恢复链接。
完成后的进度收为摘要；运行中的任务保留正常进度与取消功能。

比较默认显示“速度—质量”散点图。本程序使用较大的深绿色菱形点、“我的程序”标签，
并在方法列表、数值表和矩阵中置于首位；对照使用较小的圆点。
横轴可选时间／峰值内存，纵轴优先使用本程序可用的 Q，否则使用归一化 SP，也可切换 TC。
保留“左上更优”、对数／线性坐标、Q／TC 局部放大，以及分项指标、数值表和全部数据集矩阵。
失败、超时、不支持及未匹配对照保留状态，不绘制为零。

首次优先打开 RNA · 255 条且双方有 Q 的数据；否则依目录顺序寻找双方有 Q、归一化 SP
的用例，最后保留首个支持类型的数据集。显式选择的数据集不自动跳走。
数据集、指标、方法筛选和图形设置保存在 URL；切换数据时保留目录滚动位置。

本程序为 gVisor 用户评测；历史对照包含普通 Docker 的 16／32 GiB 测量。
界面显示简短条件标签，完整版本、参数和条件收在“实验详情”。色彩用于识别本程序，
不新增性能排名、加速倍数或自动冠军；质量值保留原报告精度。

## 无等待的真实示例

在 `/#/benchmark/submit` 选择“用 MSA-Kit 体验”，会进入明确的示例模式。
仓库预填为 `https://github.com/malabz/MSA-Kit`，固定 commit：

```text
c49b49f748902798ce90c21cb734baf11ea4a3f9
```

示例隐藏邮箱和可修改的版本设置，点击“体验评测”直接打开
`/#/benchmark/examples/msa-kit`，默认展示 RNA · 255 条。
成绩来自已完成并修订 Q 的真实评测：**25 组完整、1 组超时**。
示例提供仓库和接入脚本说明，便于准备自己的程序。

示例读取独立公开快照 `public/benchmark/examples/msa-kit.json`。
它不提交真实任务、不排队、不构建、不比对、不评分、不发邮件，也不占提交额度；
无需 GitHub 登录或私有访问密钥，不受原任务到期时间影响。
示例只公开方法、commit、数据、条件与成绩，不公开原私有 run ID、邮箱、归属、日志或路径。
普通表单即使输入同一个仓库，仍然创建正常评测；只有主动选择示例才使用现成成绩。
示例不会出现在“最近评测”的真实任务列表中。

## 数据、下载与固定快照

Comparison v1 支持动态方法 ID，独立于原公开 v2 和私有 v3。
只将原输入／参考身份和评分定义匹配的数据关联；不匹配时保留本程序，显示“暂无匹配对照”。
组合数据仅用于该用户的私有比较，不加入公共六方法矩阵。

私有比较接口为 `GET /api/benchmark/runs/:runId/comparison`，使用原 Bearer 任务密钥。
支持 `format=json|csv`、`snapshot`、`dataset`、`methods`。下载携带已加载的 snapshot ID，
固定本程序报告及对照快照；当前对照更新后，旧版下载仍读取同一份记录。
方法筛选始终包含本程序，JSON／CSV 的数据集和方法范围一致。

“对比数据”可下载当前数据集或全部数据；“本程序原始成绩”保留原接口。
下载保存时间、峰值内存、SP、Avg SP、归一化 SP、Q、TC 七项原始指标及逐条条件／来源。
内存页面显示 MiB，下载保留 KiB；缩放、突出样式和单位显示不改变原值。
